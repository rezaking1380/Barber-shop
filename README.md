# Barber Shop — Landing Page

A static, responsive landing page for a barbershop, built with pure HTML and CSS.

## Sections

- **Banner / hero** — headline, tagline and booking call-to-action
- **Features** — "Why choose us" highlights with icons
- **Services** — service list with descriptions
- **Testimonials** — customer comments carousel-style section
- **Visit shop** — opening hours and "get in touch" contact block in the footer

## Getting started

No build step — just open `index.html` in a browser.

## Tech

- HTML5, CSS3
- Google Fonts (Bebas Neue, Mochiy Pop One, Poppins)
